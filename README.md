This code powers an alarm clock I built using a small round viewfinder CRT as the display. There are no schematics for this, it exists as a one off project.
The hardware used for this was an Arduino Pro Micro, DYPlayer, and DS1307. The project was built on perfboard and uses a generic off the shelf metal case I got from Amazon.

I don't expect this project to be useful to anyone else, so this is considered a personal archive.
